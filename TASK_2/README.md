# Tic-Tac-Toe AI

## Introduction

Tic-Tac-Toe AI is a simple game developed using Python and Streamlit. In this game, a player competes against an AI opponent on a 3×3 board.

The AI uses the Minimax algorithm and Alpha-Beta Pruning to select its moves. This project helped me understand how artificial intelligence can be used to make decisions in games.

## Features

- Play against an AI opponent.
- Interactive 3×3 game board.
- AI-powered moves using the Minimax algorithm.
- Scoreboard to track wins, losses, and draws.
- Option to start a new match.
- Option to reset scores.
- User-friendly web interface.

## Technologies Used

- Python
- Streamlit
- Minimax Algorithm
- Alpha-Beta Pruning

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Tic-Tac-Toe-AI.git
   ```

2. Open the project folder:

   ```bash
   cd Tic-Tac-Toe-AI
   ```

3. Install Streamlit:

   ```bash
   pip install streamlit
   ```

4. Run the application:

   ```bash
   streamlit run app.py
   ```

## How to Play

1. Open the application in your browser.
2. Click any empty square to place your X.
3. The AI will automatically make its move using O.
4. The game ends when a player wins or the board is full.
5. Start another match using the Next Match button.
